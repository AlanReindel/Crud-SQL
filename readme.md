# CRUD Python + MySQL

Projeto desenvolvido para atividade da disciplina de Banco de Dados.

## Tecnologias
- Python
- MySQL
- mysql-connector

## Banco de dados

Nome: db_usuario

Tabela: usuarios

Campos:
- id
- nome
- email
- endereco

## Funcionalidades CRUD

Create - cria usuário
Read - lista usuários
Update - atualiza usuário
Delete - remove usuário

## Instalação

Instalar dependência:

pip install mysql-connector-python

## Executar

python crud_usuario.py
